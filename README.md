# Luvora Weddings — Under Development Website

Official coming-soon / under-development website for **Luvora Weddings** (Photography & Videography — Piliyandala, Sri Lanka).

## Live Hosting on GitHub Pages
1. Push this repository to GitHub (branch `main`).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/` within 1–2 minutes.

## Quick Customization
Edit `LUVORA_CONFIG` at the top of `script.js` to update your exact Facebook/Instagram links, development progress %, or launch countdown date.
